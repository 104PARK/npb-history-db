# NPB歴代データベース Complete V6

V5を基礎に、複合条件検索エンジンと選手中心のドリルダウン画面を追加した版です。

## 追加機能
- 複合条件検索：年度、球団、相手、球場、大会、得点、延長、ノーヒットノーラン、完全試合
- 選手検索：名前・よみ・守備位置・期間・所属球団
- 選手ページ：基本情報、所属球団履歴、年度別打撃、年度別投手、最近の出場試合
- 選手の試合実績：安打、本塁打、打点、三振、投球回、奪三振、年度、相手球団を組み合わせて検索
- 試合詳細：出場選手→打撃→投手→PBP
- 対戦成績：2球団・期間指定
- 記録検索：全選手の1試合成績を横断検索
- 検索用インデックス追加

## 起動
```bash
pip install -r requirements.txt
python migrate_v6.py
streamlit run app.py
```
Windowsでは `NPB全期間一括取込.bat` を先に実行してデータを増やしてください。

## データについて
アプリはSQLite上の取り込み済みデータを検索します。V6そのものが1936～2025年の全データを同梱するものではありません。全期間取込は既存の `full_import.py` / `game_detail_importer.py` を使用します。

NPB公式データを一次資料として扱い、取得URL・取込履歴をDBに残す設計です。外部公開データを追加する場合は出典・ライセンスを別管理してください。
