# NPB歴代データベース Complete V7

V7は「選手A/B比較」と「選手同士の実戦対戦履歴」を追加し、検索エンジンを完成形に近づけた版です。

## 主な機能
- 選手A/Bの通算成績を横並び比較
- 選手A/Bの年度別成績を同一年で横並び表示
- 所属球団履歴を比較
- 両選手が同じ試合に出場した試合一覧
- PBPに記録された直接対戦（打者×投手）の抽出
- 選手ページから年度・球団・試合へドリルダウン
- 複合条件による試合検索
- 試合→出場選手→打撃→投手→PBPの連結
- NPB公式HTMLの原本保存、取得履歴、SHA-256管理

## 一括取込
### NPB全期間一括取込.bat
1936～2025年度成績、選手マスター、1950～2025試合結果を順番に取得します。

### NPB増量取込_2020以降.bat
上記に加えて2020～2025年の試合詳細（TOP/BOX/PBP）を取得します。
大量アクセスを避けるため、最近6年を詳細化する段階的な方式です。

### NPB試合詳細一括取込.bat
既にgamesへ入っている2020～2025年の試合について、TOP/BOX/PBPを追加取得します。

## アプリ
`NPB選手比較アプリ.bat` をダブルクリックすると起動します。

## 注意
- この配布物は「取得・正規化・検索基盤」です。配布先サイトの利用規約・robots・著作権・データ利用条件を尊重してください。
- NPB公式データを一次資料として扱い、外部公開データは出典・ライセンスを確認して別ソースとして追加してください。
- 1936～1949年は現代のセ・パ制度と異なり、1936/1937年は春秋区分があるため、現代シーズンと同一視しない設計です。
